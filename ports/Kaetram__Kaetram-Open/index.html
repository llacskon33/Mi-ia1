align-items: center; } ``` ### JavaScript (script.js) ```javascript const canvas = document.getElementById('game-container'); const ctx = canvas.getContext('2d'); // Configuración de la ventana canvas.width = window.innerWidth; canvas.height = window.innerHeight; // Configuración de la cámara const camera = { position: { x: 0, y: 0 }, zoom: 1 }; // Configuración de los objetos const objects = []; // Función para dibujar objetos function drawObjects() { objects.forEach(obj => { ctx.fillStyle = obj.color; ctx.fillRect(obj.position.x, obj.position.y, obj.size.width, obj.size.height); }); } // Función para actualizar la cámara function updateCamera() { const mouse = { x: window.innerWidth / 2, y: window.innerHeight / 2 }; const deltaX = mouse.x - camera.position.x; const deltaY = mouse.y - camera.position.y; camera.position.x += deltaX * camera.zoom; camera.position.y += deltaY * camera.zoom; camera.zoom *= 0.95; } // Eventos de teclado document.addEventListener('keydown', function(event) { switch (event.key) { case 'ArrowLeft': camera.position.x -= 1; break; case 'ArrowRight': camera.position.x += 1; break; case 'ArrowUp': camera.position.y -= 1; break; case 'ArrowDown': camera.position.y += 1; break; } }); // Eventos de mouse document.addEventListener('mousemove', function(event) { updateCamera(); }); // Eventos de escucha window.addEventListener('resize', function() { canvas.width = window.innerWidth; canvas.height = window.innerHeight; }); // Eventos de carga window.addEventListener('load', function() { drawObjects(); }); ``` ### Explanation 1. **HTML**: Se crea un contenedor `div` con la clase `game-container` donde se mostrará el juego. 2. **CSS**: Se define una fuente de estilo para el documento y se establecen las propiedades de la ventana y la cámara. 3. **JavaScript**: Se inicializan los objetos y las variables necesarias para la aplicación. 4. **Eventos**: Se manejan eventos de teclado, mouse, y escucha para controlar la cámara y la visualización del juego. 5. **Drawing**: La función `drawObjects` dibuja los objetos en la pantalla. 6. **Updating Camera**: La función `updateCamera` actualiza la posición de la cámara basada en la posición del mouse. 7. **Eventos de Escucha**: Se manejan eventos de carga para cargar los objetos al iniciar la aplicación.
